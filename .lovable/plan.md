

# הוספת חלונית דרישות חלוקה לטאב חניכים

## סיכום

הפיצ'ר של "העדפת חלוקה לאוהלי לינה" כבר קיים במערכת:
- השמירה ל-Supabase עובדת (נבדק בקוד)
- התצוגה קיימת ב-`GroupAllocation.tsx` אבל מופיעה מעל הטאבים

**המשימה**: להוסיף פאנל מידע מקוצר בתוך טאב "חניכים" עם תצוגה מקובצת ופירוט מתרחב.

---

## מה יתווסף

### פאנל דרישות חלוקה בטאב חניכים

```text
┌────────────────────────────────────────────────────┐
│  📋 דרישות חלוקה מהזמנה                           │
│  ─────────────────────────────────────────────────  │
│  • 7 אוהלים × 8 אנשים                              │
│  • 3 אוהלים × 5 אנשים                              │
│                                                    │
│  סה"כ: 50 | חניכים: 50 ✓                           │
│                                                    │
│  [הצג פירוט ▼]                                     │
│  ─────────────────────────────────────────────────  │
│  │ 1:8  2:8  3:8  4:8  5:8  6:8  7:8  8:5  9:5  10:5│
│  ─────────────────────────────────────────────────  │
│                                                    │
│  ℹ️ זהו מידע תכנוני בלבד.                          │
│     השיבוץ בפועל מתבצע בבחירת שכונות/אוהלים בהמשך.  │
└────────────────────────────────────────────────────┘
```

### פיצ'רים:
- **סיכום מקובץ**: מציג כמה אוהלים לפי כמה אנשים (למשל "7 × 8" ו-"3 × 5")
- **סטטוס תקינות**: סימון ירוק אם הסכום תואם, כתום עם אזהרה אם לא
- **פירוט מתרחב**: לחיצה על "הצג פירוט" מציגה את רשימת האוהלים המלאה
- **הודעת מידע**: הסבר שזו העדפה בלבד, לא שיבוץ

### לוגיקת קיבוץ

הפונקציה תקבץ את האוהלים לפי מספר האנשים:
```typescript
// קלט: [{ index: 1, pax: 8 }, { index: 2, pax: 8 }, { index: 3, pax: 5 }]
// פלט: [{ pax: 8, count: 2 }, { pax: 5, count: 1 }]
function groupTentsByPax(tents) {
  const groups = {};
  tents.forEach(tent => {
    groups[tent.pax] = (groups[tent.pax] || 0) + 1;
  });
  return Object.entries(groups)
    .map(([pax, count]) => ({ pax: Number(pax), count: Number(count) }))
    .sort((a, b) => b.count - a.count);
}
```

## מה לא ישתנה

- לא יווצרו רשומות בטבלאות `allocations` או `neighborhood_reservations`
- הפאנל הוא read-only בלבד
- הלוגיקה של שיבוץ השכונות נשארת כמות שהיא
- VIP, לוח שנה, מטבח - ללא שינוי

## בדיקות קבלה

1. צור קבוצה עם 50 חניכים והגדר העדפה: 7 אוהלים × 8 אנשים + 3 אוהלים × 5 אנשים
2. שמור את הקבוצה
3. רענן את הדף - העדפה נשמרת
4. פתח טאב שיבוצים → חניכים - הפאנל מוצג בראש הטאב
5. הפאנל מציג סיכום מקובץ (לא רשימה ארוכה)
6. לחיצה על "הצג פירוט" מציגה את כל האוהלים
7. וודא שאין שיבוצים או הזמנות חדשות במסד הנתונים
