
## שינוי: הצגת שדות צרכים מיוחדים תמיד

### בעיה
כרגע שדות הצרכים המיוחדים (צמחוני, טבעוני, ללא גלוטן, ללא לקטוז, אלרגיות, והערות) מוסתרים עד שהמשתמש מזין כמות סועדים > 0.

### פתרון
הסרת התנאי `{meal.pax > 0 && (` כך ששדות הצרכים המיוחדים יוצגו תמיד, ללא תלות בכמות הסועדים.

---

### שינוי בקובץ

**קובץ:** `src/pages/AdminGroupEdit.tsx`

**לפני (שורות 1183-1184):**
```tsx
{/* Special needs - shown only when pax > 0 */}
{meal.pax > 0 && (
  <div className="mt-3 pt-3 border-t space-y-3">
    ...
  </div>
)}
```

**אחרי:**
```tsx
{/* Special needs - always shown */}
<div className="mt-3 pt-3 border-t space-y-3">
  ...
</div>
```

---

### מה ישתנה
| לפני | אחרי |
|------|------|
| שדות הצרכים המיוחדים מוסתרים כשכמות סועדים = 0 | שדות הצרכים המיוחדים מוצגים תמיד |

---
