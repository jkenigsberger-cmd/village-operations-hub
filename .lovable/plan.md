

# שינוי שם + הטמעת לוגואים (הדור הבא + GLOW)

## מה ישתנה

### 1. שמירת תמונת הלוגואים בפרויקט
- העתקת הקובץ שהעלית ל-`src/assets/logos.png`
- התמונה תשמש גם ב-Header וגם ב-Footer

### 2. Header (כותרת העמוד)
- הסרת אייקון האוהל והשם "חוות אהרונסון"
- במקום: תמונת הלוגואים (גודל מותאם, כ-120px גובה בדסקטופ, 80px במובייל)
- הרקע השחור בתמונה ישתלב יפה עם header כהה, או שנוסיף `rounded` עם רקע כהה מאחורי הלוגו

### 3. Footer חדש (בתחתית כל עמוד)
- רכיב `PartnerFooter.tsx` חדש
- מציג את תמונת הלוגואים בגודל קטן יותר
- טקסט: "by הדור הבא & GLOW Alternative Hospitality"
- רקע כהה כדי שהלוגואים (ירוק + כחול) ייראו טוב

### 4. עדכון כותרת HTML
- `<title>` ישתנה ל: "הדור הבא — GLOW Glamping"
- עדכון meta description

## שאלה אחת על הרקע

התמונה שהעלית היא על רקע שחור. שתי אפשרויות:
- **אופציה א**: להשתמש בתמונה כמו שהיא ולהוסיף רקע כהה מאחורי הלוגו ב-Header וב-Footer
- **אופציה ב**: אם יש לך גרסה של הלוגואים על רקע שקוף (PNG שקוף), תעלה אותה ונשתמש בה — זה ייראה יותר נקי

כרגע אתקדם עם אופציה א (רקע כהה) וניתן לעדכן בהמשך.
